# Sustainable Materials AI: Data Engineering & Visualization Pipelines

This repository serves as a centralized portfolio demonstrating core data foundations, advanced visualizations, and engineering pipelines tailored for Green Chemistry and Computational Material Science.

## 🛠️ Repository Framework

### 📊 Data Visualization & Foundations
- **NumPy & Matplotlib Foundations:** Array manipulation of chemical metrics, custom plotting standards, and multi-axes figure layouts.
- **Seaborn Advanced Visualizations:** Publication-grade categorical Bar Plots, frequency Histograms with KDE curves for particle size clusters, and Correlation Matrix Heatmaps for chemical feature relationship screening.

### 🧼 Data Preprocessing Pipeline
- **Missing Value Resolution:** Robust mean imputation for null data strings.
- **Outlier Elimination:** Z-Score based statistical thresholding to clean anomalous dataset noise.
- **Feature Scaling:** Min-Max normalization mapping multivariable inputs precisely to a 0.0 - 1.0 range.
